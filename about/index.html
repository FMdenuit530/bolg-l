# 关于我

你好，欢迎来到我的博客。

这里没有刻意包装成一份正式简历。

我更希望它像一个长期记录的空间：

记录我学习过的东西，
记录我做过的项目，
记录开发过程中遇到的问题，
也记录一些值得留下来的思考。

# 关于这个博客

这个博客主要记录三个方向：

# 学习

把平时学习 JavaScript、Vue、Git 以及其他技术知识时遇到的问题记录下来。

有些内容可能很基础，但我希望把它们认真整理下来。

因为真正理解一个知识点，往往不是“看懂”的那一刻，而是能够把它重新讲清楚的时候。

# 实践

这里也会记录一些实际开发过程。

包括：

  • 项目开发
  • 页面制作
  • VuePress
  • Git
  • GitHub
  • 前端开发
  • 一些有趣的小工具

我希望这些记录不仅仅是“怎么写代码”，还能够留下为什么这样做，以及过程中遇到了什么问题。

# 思考

技术之外，也会留下一些自己的思考。

可能是一篇文章。

可能是一段开发经历。

也可能只是某一天突然想到的一件事情。

博客对我来说，不只是知识库。

更像是一份慢慢积累起来的个人记录。
